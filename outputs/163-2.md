## Supabase 개요

> **Supabase (Supabase)**
>
> PostgreSQL 데이터베이스 엔진 기반으로 구축되어 데이터베이스, 인증, 스토리지, 실시간 통신 등을 즉시 제공하는 오픈소스 BaaS 플랫폼

- **BaaS의 특징**: 백엔드 서버 인프라 구축 없는 즉각적인 고기능 클라우드 서비스 제공
- **핵심 기반**: 신뢰성 높은 PostgreSQL 엔진 기반으로 안정적인 관계형 데이터 관리 지원

## Supabase 보안 메커니즘 (Anon Key & RLS)

- **Anon Key (익명 API 키)**
  - 브라우저에 직접 노출되어도 무방한 클라이언트용 공개용 접근 식별자
- **RLS (Row Level Security)**
  - 테이블 단위 통제에서 벗어나 개별 행(Row) 수준으로 조회를 제한하는 핵심 기술
- **RBAC (역할 기반 제어) 연동**
  - 접속 유저 등급(`anon` 익명 유저, `authenticated` 로그인 유저 등)에 따른 투명한 데이터 필터링

## 데이터베이스 스키마와 RDB

> **스키마 (Schema)**
>
> 데이터가 기록되는 표(Table)의 규격, 컬럼 데이터 타입 및 외래키 등 제약조건을 사전 정의한 데이터베이스 설계도

- **SQL**: 관계형 데이터베이스(RDB)를 제어하고 가공하는 질의 표준 언어
- **테이블 설계**: 데이터 간의 연계 관계를 논리적인 표 구조로 시각화하여 설계하는 과정

## [실습] posts 테이블 생성 SQL

```sql
-- 게시글(posts) 테이블 정의
create table posts (
  id bigint generated by default as identity primary key,
  title text not null,
  content text not null,
  created_at timestamp with time zone default now() not null
);
```

## [실습] comments 테이블 생성 SQL

```sql
-- 외래키 및 Cascade 삭제를 포함하는 댓글(comments) 테이블 정의
create table comments (
  id bigint generated by default as identity primary key,
  post_id bigint references posts(id) on delete cascade not null,
  commenter text not null,
  content text not null,
  created_at timestamp with time zone default now() not null
);
```

## Supabase Auth & 인증 아키텍처

> **Supabase Auth (Auth)**
>
> 클라이언트 단에서 직접 회원가입, 로그인, 세션 유지 등의 계정 관리를 수행할 수 있는 내장 보안 인증 서비스

- **JWT 기반 제어**: 가입 및 인증 성공 시 JSON Web Token을 로컬 스토리지에 자동 보관 및 관리
- **다양한 소셜 연동**: 동일한 메서드 구조 안에서 구글, 카카오 등 서드파티 OAuth 연동 즉각 확장

- **엔드포인트 자동 빌드**

## REST API with Axios (데이터 조회)

```javascript
// Axios 활용 REST API 헤더 및 파라미터 조립 조회 예시
const response = await axios.get(`${SUPABASE_URL}/rest/v1/posts`, {
  headers: {
    'apikey': SUPABASE_ANON_KEY,
    'Authorization': `Bearer ${SUPABASE_ANON_KEY}`
  },
  params: { select: '*', order: 'created_at.desc' }
});
```

## SDK 클라이언트 초기화 및 조회

```javascript
// Supabase 클라이언트 초기화 및 생성
const supabaseClient = supabase.createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

// 데이터 조회 (Select)
const { data, error } = await supabaseClient
  .from('posts')
  .select('*')
  .order('created_at', { ascending: false });
```

## Object Storage와 파일 업로드

- **바이너리 파일 저장 구조**
  - 고용량 미디어 파일(이미지/비디오)은 DB가 아닌 Object Storage에 보관하고 URL 문자열만 DB에 기입
- **SDK 연동 파일 업로드**
  - 수동 파일 청크 전송 없이 SDK의 storage 메서드를 통하여 파일 바이너리를 클라우드에 직접 주입

## SDK 기반 단일 파일 업로드

```javascript
// 'avatars' 버킷 업로드 및 즉각적인 Public URL 획득
const { data, error } = await supabaseClient.storage
  .from('avatars')
  .upload(`public/${Date.now()}_${file.name}`, file);

if (error) throw error;

const { data: { publicUrl } } = supabaseClient.storage
  .from('avatars')
  .getPublicUrl(data.path);
```
